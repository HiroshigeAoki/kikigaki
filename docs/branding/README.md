# kikigaki アイコン原本

採用する新しいアプリアイコンの原本です。

![kikigaki アイコン](kikigaki-icon-source.png)

- 濃紺・生成り・朱色の配色で、「聞く・書く」を表現します。
- 外周の円や立体的な素材感を減らしたデザインです。
- `kikigaki-icon-source.png` は承認された生成画像をそのまま保存しています（1254 × 1254、RGB PNG）。
- 原本には透過チャンネルがなく、角丸の外側は黒背景です。配布用への変換時に外側の透過処理と余白調整が必要です。
- 配布用PNG・ICNSとメニューバー用の小サイズ画像は、この原本を基準に作成してください。メニューバーでは状態の識別とライト／ダークモードでの視認性を維持してください。

この追加は原本の保存のみです。アプリへの組み込み、派生画像の生成、各画面での表示確認は別Issueで管理します。
